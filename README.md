# Кабинет ППР — Пинигинский проект

Внутреннее веб-приложение (Next.js 15). Кабинет проекта «Пинигинское»: обзор, бурение,
неделя, расходы, керн, техника, лицензии, запасы, вехи/задачи, источники. Вход по паролю.

## Локальный запуск
```
npm install
npm run dev        # http://localhost:3000
```
Пароль по умолчанию — PPRGold2026 (переопределяется переменной CABINET_PASSWORD).

## Деплой на Vercel (под корпоративным аккаунтом)
1. Создать репозиторий в организации на GitHub, запушить эту папку.
2. На vercel.com под корпоративным аккаунтом: Add New → Project → импорт репозитория.
3. Framework Preset определится автоматически (Next.js). Build не менять.
4. Project Settings → Environment Variables: добавить `CABINET_PASSWORD` со своим значением.
5. Deploy. Приложение получит адрес вида ppr-cabinet.vercel.app (можно привязать домен компании).

## Обновление данных
Все показатели — в одном файле `lib/data.ts` (типизированные структуры).
Правка значений там автоматически обновляет все страницы. Следующий этап —
замена этого модуля на подключение к базе данных (PostgreSQL) без изменения компонентов.

## Структура
```
app/            маршруты (login, cabinet/*, api/login, api/logout)
components/      Sidebar, Topbar, KPI/Bars/Progress, иконки
lib/data.ts     единый источник данных (заменяется на БД)
lib/auth.ts     проверка cookie
middleware.ts   защита /cabinet паролем
```
