# Кабинет ППР — как выложить на Vercel СЕГОДНЯ (10–15 минут)

Приложение уже собрано, проверено и лежит в архиве `ppr-cabinet-исходники.tar.gz`.
Ниже — самый быстрый путь получить рабочую ссылку без участия ИТ и без GitHub:
через официальную консольную утилиту Vercel, прямо с твоего компьютера.

Позже, когда будет готов корпоративный аккаунт, проект можно перенести на него
в один клик (Vercel → Transfer Project) — сегодняшняя ссылка не потеряется.

---

## Что понадобится
- Аккаунт на vercel.com (можно завести за минуту на личную почту — это нормально,
  перенесём на корпоративный позже).
- Node.js на компьютере (у тебя уже стоит — это видно по терминалу на скринах).
- Архив `ppr-cabinet-исходники.tar.gz` — распакуй в любую папку.

## Шаги

**1. Распаковать архив**
Дважды кликнуть на `ppr-cabinet-исходники.tar.gz` (macOS распакует сам)
— появится папка `ppr-app`.

**2. Открыть терминал в этой папке**
```
cd путь/до/папки/ppr-app
```

**3. Установить зависимости** (один раз)
```
npm install
```

**4. Войти в Vercel** (откроется браузер для подтверждения — это твой личный вход,
никаких паролей никому вводить не нужно)
```
npx vercel login
```

**5. Задать пароль входа в кабинет**
```
npx vercel env add CABINET_PASSWORD production
```
Терминал спросит значение — введи пароль, который будешь сообщать коллегам для входа
в кабинет (например, тот же принцип, что был у старого кабинета).

**6. Выложить**
```
npx vercel --prod
```
Ответить на вопросы по умолчанию (Enter), задать имя проекта, например `ppr-cabinet`.
Через 30–60 секунд терминал выдаст ссылку вида `https://ppr-cabinet-xxxx.vercel.app` —
это и есть рабочий адрес кабинета.

**7. Проверить**
Открыть ссылку → страница входа → ввести пароль из шага 5 → должен открыться
кабинет с боковым меню (Обзор, Бурение, Неделя, Расходы, Керн, Техника, Лицензии,
Запасы, Вехи, Источники).

---

## Если что-то пошло не так
- «command not found: npx» — значит нет Node.js, тогда этот путь не подходит,
  сообщи мне, дам альтернативу через веб-интерфейс Vercel.
- Просит GitHub — не должен на этом пути; если появилось окно про репозиторий,
  просто закрыть его и продолжить в терминале.
- Пароль не подходит на странице входа — проверь, что задавал именно
  `production`-окружение на шаге 5, и подожди 1 минуту после деплоя (кэш).

## Дальше (не срочно)
- Когда будет корпоративный аккаунт Vercel — Project Settings → Transfer Project.
- Обновление данных — правка одного файла `lib/data.ts` и повторный `npx vercel --prod`.
